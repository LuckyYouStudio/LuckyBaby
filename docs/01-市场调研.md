# 孕期家庭共享记录 App —— 市场调研报告

日期：2026-09-04

## 1. 一句话结论

国内孕期 App 是"内容社区 + 电商 + 广告"的红海，但**"一家人一起记录孕期、以产检/用药/生活为核心、无广告无社区"**这个细分位置没有被认真做过。准爸爸和祖辈在现有产品里都是"旁观者"，而不是"参与者"。这是一个小而清晰的切口，适合做成付费买断、隐私优先的工具型产品。

## 2. 宏观盘子

| 指标 | 数值 | 来源 |
|---|---|---|
| 2025 年中国出生人口 | 792 万（2024 年 954 万） | 国家卫健委统计公报 |
| 2025 年出生率 | 5.63‰ | 国家统计局 |
| 2021–2025 年出生人口 | 1062 / 956 / 902 / 954 / 792 万 | 国家卫健委 |
| 全球孕期+育儿 App 市场 | 2025 年约 28.8 亿美元，2035 年预计 85 亿美元 | 行业报告（口径差异很大，仅供参考） |

解读：
- 每年约 800 万孕妇，对应约 800 万个"家庭单元"（准妈妈 + 准爸爸 + 双方父母）。用户基数在缩小，但**每个孩子受到的关注度和投入在上升**，"全家参与"的意愿更强。
- 出生人口连年下滑意味着靠广告/流量的大平台模式越来越难，反而利好**小而美、按家庭付费**的工具型产品。

## 3. 国内竞品格局

| 产品 | 定位 | 家人/准爸爸参与方式 | 商业模式 | 主要问题 |
|---|---|---|---|---|
| 宝宝树孕育 | 老牌综合社区，AI 管家"米卡"，AI 解读 B 超单 | "爸爸版"：准妈妈用邀请码邀请，爸爸看孕期知识 | 广告 + 电商 + 会员 | 功能臃肿；2024-11 被曝准爸爸注册后频繁收到涉黄短信/骚扰电话 |
| 妈妈网孕育 | 同城/同院圈社交，本地建档信息 | 无明确家庭共享 | 广告 + 电商 | 社区噪音大，信息流广告多 |
| 美柚 | 经期起家，"模式切换"备孕/怀孕/育儿 | 无明确家庭共享 | 广告 + 电商 | 同样被曝准爸爸注册后收到骚扰短信；收集信息清单极长 |
| 亲宝宝 | 以宝宝为中心的私密云相册，1 亿注册用户 | 一人上传全家共享（照片/视频为主） | 广告 + 电商 + 会员 | 孕期只是附属；重"相册"轻"健康记录" |
| 孕期伴侣 | 系统化孕期课程，商业化推送少 | 无 | 内容付费 | 只覆盖孕期，不做家庭协作 |

关键观察：
1. **所有头部产品的"爸爸功能"都是"让爸爸学知识"，不是"让爸爸一起干活"。** 没有产品把"谁陪产检、谁提醒吃叶酸、谁记录血压"这类协作动作做成核心。
2. **隐私是真实的痛点，不是营销话术。** 2024 年 11 月澎湃、21 财经等媒体集中报道：准爸爸注册美柚/宝宝树后收到涉黄短信，宝宝出生后注销才停止。两家公司否认泄露，但用户信任已经受损。
3. **产检记录功能存在但埋得很深。** 宝宝树有"AI 解读 B 超单"、产检时间表，但被社区、电商、广告包围；用户吐槽"只想记个产检，打开全是推荐"。
4. 政务侧的"电子母子健康手册"（北京、深圳妇幼小程序）解决了建档，但**不面向家庭共享**，也没有生活/用药记录。

## 4. 海外参照

| 产品 | 亮点 | 借鉴点 |
|---|---|---|
| HiDaddy / HiMommy | 两个 App 互相同步，爸爸和妈妈各看各的视角 | "同一份数据，两种视角" |
| Dad's Journey | 专为爸爸设计，DadBot AI 按孕周答疑 | 爸爸视角的文案和任务 |
| BumpSync | 专门做"情侣一起追踪孕期" | 验证了"couple-first"的定位可行 |
| Ovia | Friends & Family Sharing，可选择分享内容 | 分享粒度可控 |
| Glow | 曾被 Consumer Reports 曝出情侣绑定的隐私漏洞 | 共享权限必须做细，不能"绑定即全开" |
| Apple 健康 | iOS 15 起可把健康数据共享给家人；可记录孕期 | 系统级共享存在，但太"数据"，不"生活" |

## 5. 目标用户与真实需求

调研（知乎、小红书、母婴社区帖子）里反复出现的话：

**准妈妈**
- "产检单子一堆，拍了照发家庭群，过两天就找不到了。"
- "老公问我今天检查什么，我懒得解释第二遍。"
- "叶酸/钙片/铁剂经常忘，希望有人提醒我。"
- "婆婆/我妈总打电话问情况，想让他们直接看到。"

**准爸爸**
- "想参与但不知道能做什么，下了宝宝树全是妈妈社区。"
- "记不住产检日期，想要提醒。"
- "想知道这次检查结果正不正常，看不懂单子。"

**祖辈**
- "只想知道孩子好不好、什么时候产检、要不要去陪。"
- 不会用复杂 App，最好像看朋友圈一样。

## 6. 市场机会与风险

机会：
- 头部产品因"广告 + 电商"模式与用户利益冲突，留出**"付费买清净"**的空间。
- 出生人口下降 → 每个家庭投入上升 → 对"高质量陪伴"的付费意愿上升。
- 隐私事件让"我们不卖数据、不发短信"成为可信的卖点。

风险：
- 用户生命周期短（约 10 个月），获客成本要低（靠口碑、准妈妈邀请家人自带传播）。
- 头部产品可以复制"家庭共享"功能；护城河在于**克制**（不做社区、不做电商）和体验。
- 医疗合规：只能做"记录 + 参考区间提示"，不能做诊断结论。
- 《个人信息保护法》：健康数据属敏感个人信息，需**单独同意**；权限须按需申请。
