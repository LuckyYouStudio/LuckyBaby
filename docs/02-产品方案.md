# 产品方案：「幸运宝贝」—— 一家人一起记录的孕期

日期：2026-09-04

## 1. 定位

**一句话**：一个家庭共用的孕期记录本。准妈妈记录，准爸爸参与，家人了解。

**三个"不做"**（这是护城河，也是与宝宝树/美柚最大的区别）
1. 不做社区、不做信息流。
2. 不做电商、不做广告、不发营销短信。
3. 不做诊断。只记录、提醒、给参考区间。

**产品名**：幸运宝贝（LuckyBaby）。

## 2. 用户角色与权限

| 角色 | 典型人 | 能做什么 | 默认看到什么 |
|---|---|---|---|
| 准妈妈（Owner） | 孕妇本人 | 一切；管理家庭成员、可见范围 | 全部 |
| 准爸爸（Partner） | 丈夫 | 记录、提醒、陪产检打卡、添加照片、评论 | 全部（准妈妈可关闭"敏感项"） |
| 家人（Family） | 双方父母、兄弟姐妹 | 看动态、点赞/留言、看产检日程 | 孕周、动态、产检日程；**不看**检查数值、用药明细 |

原则：**准妈妈拥有数据**。任何一条记录都有"仅自己 / 伴侣 / 全家"三档可见性，默认按类别设定。这是针对宝宝树/美柚隐私事件的正面回答。

## 3. 核心功能（MVP）

### 3.1 首页：今天
- 孕周 + 天（按末次月经或 B 超推算，可修正预产期）
- 宝宝本周大小（用水果/蔬菜类比 + 一句话发育）
- 今天要做的事：待吃的补充剂、即将到来的产检、家人留下的待办
- 家庭动态流（最近 3 条）

### 3.2 产检
- **内置中国标准产检时间表**（建档 6–12 周、NT 11–13⁺⁶ 周、唐筛/无创 16–18 周、大排畸 22–24 周、糖耐 24–28 周、胎心监护 36 周起、每周一次至分娩），按孕周自动排入。
- 每次产检：时间、医院、项目、**谁陪同**、注意事项（空腹/憋尿）、结果照片、关键数值（血压、体重、宫高、腹围、胎心、血糖、血红蛋白），数值给参考区间提示。
- 准爸爸一键"我陪"，日历提醒双方。

### 3.3 用药与补充剂
- 预置叶酸（0.4–0.8 mg，孕前 3 月至孕 12 周）、钙（孕中期起 600 mg/天）、铁、DHA、维生素 D，可自定义处方药。
- 每日打卡。**准爸爸可以替她打卡**（"我给她吃了"），也可以收到"她今天还没吃"的提醒。

### 3.4 生活记录
- 体重曲线（含孕期推荐增重区间）
- 症状（孕吐、水肿、失眠……）与心情
- 胎动计数（孕 28 周起）
- 宫缩计时（孕晚期）
- 照片：肚肚照、B 超照，按孕周归档

### 3.5 家庭
- 邀请码 / 链接邀请，选角色
- 每个成员的头像 + "最近做了什么"（陪了 2 次产检、提醒了 5 次吃药）
- 动态流：所有记录自动变成一条动态，家人可点赞/留言

### 3.6 提醒
- 产检前 1 天 + 当天早上
- 补充剂每日固定时间；漏打卡 2 小时后提醒伴侣
- 孕周变更（每周一早上给全家推"本周宝宝……"）

## 4. 后续版本（不进 MVP）
- OCR 识别检查单，自动提取数值
- 产后无缝过渡（新生儿喂养、疫苗），延长生命周期
- Apple 健康读写（体重、孕期）
- 微信小程序版本作为家人端（祖辈不装 App）
- 导出 PDF"孕期手册"（可打印，也是留念）

## 5. 商业模式

- 免费：单人使用，全部功能。
- 家庭版：**一次买断 ¥68**，或 ¥12/月。解锁邀请家人、云端同步、照片云存储。
- 不做广告、不卖数据、不发营销短信，并写进隐私政策。
- 目标：第一年 1 万个付费家庭 ≈ 68 万元收入，验证模式后再谈增长。

## 6. 技术方案

| 层 | 选择 | 理由 |
|---|---|---|
| 客户端 | Expo（React Native）+ TypeScript | 一套代码 iOS + Android。准爸爸/祖辈很可能用安卓；本机已有 Node 22 与 Xcode 26 可直接跑模拟器 |
| 本地存储 | expo-sqlite + 仓储层（Repository） | 离线优先；产检现场信号差也能记录 |
| 云同步 | Supabase（Postgres + RLS + Realtime） | 行级安全直接实现"按角色可见"；国内访问慢的话可平移到腾讯云开发 |
| 推送 | expo-notifications | 本地提醒先做；远程推送（提醒伴侣）走 Supabase Edge Function |
| 照片 | 本地压缩后上传对象存储 | 只传家庭内可见 |
| 隐私 | 健康数据类别"单独同意"弹窗；权限用到时再申请 | 符合《个人信息保护法》与 2025 年 App 监管要求 |

数据模型（核心表）：
- `families`（家庭）、`members`（成员+角色）、`pregnancy`（末次月经/预产期）
- `checkups`（产检）、`checkup_metrics`（数值）
- `supplements`、`supplement_logs`（打卡，记录 by 谁）
- `daily_logs`（体重、症状、心情、胎动）
- `photos`、`posts`（动态）、`comments`
- 每条记录带 `visibility: self | partner | family`

## 7. 视觉方向

- 不用粉红婴儿风。用**暖米白纸张感 + 深松绿 + 杏色**，像一本手写的孕期手册。
- 圆角克制，信息密度适中，字号偏大（祖辈可读）。
- 每个成员一个颜色，动态流里一眼看出"是谁记的"。
