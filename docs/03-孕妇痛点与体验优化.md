# 孕妇痛点与体验优化

日期：2026-09-05。来源：知乎「大家孕期崩溃到哭都是因为什么」「孕晚期到底有多难受」、少数派准妈妈孕期记录、北妇产产检流程经验帖、PLOS One 对 10 款孕期 App 426 条评论的分析、北京卫健委产检科普。

## 一、按孕期阶段的真实痛点

### 孕早期（0–13 周）：没精力
- "每一天都是数着一小时一小时度过的"，一天吐二三十次，体重掉 8 斤。
- 孕反严重时**看手机、看字都会加重恶心**，只想躺着。
- 食欲丧失，只能吃水果；被长辈和老公过度限制饮食，心情低落。
- 建档材料各医院不一样，"查清楚再去，以防白跑一趟"。

→ 对 App 的要求：**能不打字就不打字，一下点完就走**。首页顶部放三个大按钮"今天：还好 / 吐了 / 累瘫"，点一下就记完，家人就知道她今天怎么样，不用再问。

### 孕中期（14–27 周）：产检密集，容易踩坑
- 空腹项目忘了空腹、当天去太晚抽血窗口拥挤。
- 大排畸没提前约，"别指望现场窗口捡号"。
- 每次必带三样：大白本（病历）、母子手册/电子条码、医保卡/就诊码，常落在车里或家里。
- 挂号渠道混乱（京医通 / 114 / 医院公众号）。
- 报告单拍照发家庭群，复诊时医生要看上次的，翻不到。

→ 对 App 的要求：
1. **产检前一天晚上 20:00 提醒**：明天几点、要不要空腹、带什么。当天早上再提醒一次。准爸爸同时收到。
2. 每次产检自带"**带什么**"清单，默认三样，可勾。
3. 产检**报告照片**直接挂在那次产检下，按孕周归档，复诊时一翻就有。
4. 大排畸、糖耐这类要提前预约的，在上一次产检完成时提示"记得约"。

### 孕晚期（28–40 周）：身体沉，睡不好，焦虑
- 胎儿压迫，每晚起夜 3–5 次；失眠；腿抽筋、反酸。
- 胎动踢到肋骨"很疼"；数胎动一天三次每次一小时，容易忘、容易数乱。
- 担心什么时候发动；产前焦虑，"总想粘着丈夫，要有人陪"。
- 手脚水肿，手指变粗；视力可能变化。

→ 对 App 的要求：
1. **数胎动**做成一整屏的大按钮，一只手拇指就能按，屏幕常亮，一小时自动结束并保存。
2. 夜里用：深色模式、大字号（下一版）。
3. **待产包清单**全家可见，准爸爸可以认领准备。
4. 宫缩计时（下一版）。

### 贯穿全程：信息焦虑
- PLOS One 分析 96 条负面评论：社区帖子"吓人"、体重羞辱式文案、重复推送、字太小、配色刺眼、更新后日记丢失。
- 用户想要：无 body-shaming 的专业内容、深色主题、双胎/试管选项。

→ 对 App 的要求：不做社区（已定）；数值超出参考范围只说"和医生聊聊"，不用红色警告色吓人；数据本地优先永不丢；字号偏大。

## 二、本次落地的改动

| 痛点 | 改动 | 位置 |
|---|---|---|
| 孕吐没精力，不想打字 | 首页"今天怎么样"三个大按钮，一点即记 | 今天 |
| 忘空腹、忘带东西 | 产检前一天 20:00 + 当天 8:00 本地提醒，文案含空腹与携带物品 | 提醒 |
| 每次带什么 | 产检详情"带什么"清单，默认大白本/母子手册/医保卡，可勾可加 | 产检详情 |
| 报告单找不到 | 产检详情可拍照/选图，缩略图挂在该次产检下 | 产检详情 |
| 忘吃叶酸钙片 | 每种补充剂按设定时间每日提醒 | 提醒 |
| 数胎动麻烦 | 全屏大按钮胎动计数器，一小时自动保存 | 记录 → 数胎动 |
| 数值吓人 | "偏高/偏低"改为柔和提示"建议和医生聊聊" | 产检详情 |
| 待产包 | 孕晚期清单，可勾选（本版本本机保存） | 记录 → 待产包 |

## 三、第二轮已落地（2026-09-05）
- 深色模式 / 字号设置：家庭页 → 外观与字号；跟随系统 / 浅色 / 深色，标准 / 大 / 特大
- 宫缩计时：一按开始一按结束，自动算持续与间隔，达到 5-1-1 会提示
- 报告照片云端同步：私有存储桶，家人可见，签名链接
- 提醒伴侣：云端定时任务已部署；远程推送待 Apple 开发者账号 + EAS；过渡为准爸爸手机本地提醒
