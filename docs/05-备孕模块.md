# 备孕模块（2026-09-05）

## 为什么
不少家庭是从备孕就想一起记：她记月经，他想知道"哪几天该在家"。市面上的经期 App 是单人工具，准爸爸参与不进来；孕期 App 又要等怀上才开始。备孕 → 怀孕在同一个家庭里连续记录，是差异点之一。

## 做了什么
- 建家庭时可选「已怀孕」或「备孕中」。备孕只填上次月经第一天、平均周期、经期天数。
- 首页（备孕模式）：周期第几天、周期进度条（经期/易孕期/最佳时机/今天）、今天怀孕几率（高/中/低）与一句建议、一键记录（月经来了/走了、同房、排卵试纸阳性/阴性）。
- 备孕日历 `/cycle`：月视图（已记录的月经、预测月经虚线、易孕期、最佳时机深绿、排卵日 ★、同房 💕、试纸阳性点），点任意一天补记；历次周期长度；周期设置；「我怀孕了 🎉」。
- 「我怀孕了」：按上次月经 +280 天算预产期，切到孕期模式，铺产检模板与补充剂模板，保留备孕期记录，发一条家庭动态。
- 提醒（本机）：易孕期开始 9:00、最佳时机第一天 20:00、月经该来那天 9:00；准妈妈和准爸爸各收一份，文案不同。
- 补充剂：备孕期只留叶酸和维生素 D（孕前 3 个月就该吃）；产检只有一项「孕前检查」（夫妻一起）。

## 算法（只做估算，不做诊断）
- 平均周期 = 最近 ≤6 个完整周期的均值（剔除 <15 或 >60 天的异常值）；不足两个周期用用户填的数字。
- 下次月经 = 上次月经第一天 + 平均周期；排卵日 = 下次月经 − 14（黄体期按 14 天）。
- 易孕期 = 排卵日前 5 天到后 1 天；最佳时机 = 排卵日前 2 天到当天（几率「高」），其余易孕期「中」。
- 本周期有排卵试纸阳性时，排卵日改为阳性次日，下次月经随之调整。
- 最近周期最长与最短相差 >7 天视为不规律，界面提示误差大、建议配合试纸。
- 明确写出：不能用于避孕；有疑问咨询医生。

## 权限
- 备孕记录（cycle_logs）只有准妈妈、准爸爸可读写，家人角色在数据库层（RLS）就看不到；家人首页只显示「备孕中」。
- 月经、试纸、体温由准妈妈记；同房两人都可以记。

## 数据
- `families.stage`（ttc/pregnant）、`cycle_len`、`period_len`；`due_date` 允许为空。
- 新表 `cycle_logs`：kind ∈ period_start / period_end / sex / lh_pos / lh_neg / bbt / note。
- 家庭信息现在也参与同步：准妈妈切换阶段或改周期长度，准爸爸手机拉取后自动跟上。

## 之后可以做
- 基础体温曲线图；排卵后体温上升作为第二个排卵信号。
- 备孕期专属"孕前准备清单"（叶酸、疫苗、牙科、停药、戒烟酒）。
- 试孕几个周期没成功时的温和提示（一般 12 个月未孕建议就医，35 岁以上 6 个月）。
